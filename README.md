# Duroflex — Luxury Architectural Comfort & Sleep Experience

A premium, cinematic, highly animated e-commerce web application for **Duroflex**, inspired by high-end luxury architectural and interior-design showcases.

![Duroflex Luxury E-Commerce](https://images.unsplash.com/photo-1631049307264-da0ec9d70304?auto=format&fit=crop&w=1600&q=85)

## 🎨 Creative & Aesthetic Direction

- **Luxury Architectural Aesthetic**: Warm neutral color palette (`#FBF9F5` warm off-white, `#121212` charcoal, `#C2A684` muted bronze), generous whitespace, Cormorant Garamond serif headings, and Plus Jakarta Sans body typography.
- **Cinematic Motion**: Smooth layered transitions (`clip-path`, `opacity`, `scale`), sticky camera scroll scenes, interactive before/after transformation slider, and subtle custom cursor.
- **Doctor Recommended Sleep Technology**: Interactive breakdown of 5-zone orthopaedic support, CoolGel™ thermoregulation, and Swiss antimicrobial protection.

---

## 🛠️ Technology Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm installed on your machine.

### Installation & Local Run

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd duroflex-luxury-ecommerce
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173/` in your browser.

## 📦 Features Breakdown

1. **Cinematic Brand Film Intro**: Logo reveal with smooth background bedroom backdrop transition (1.5–2.5s duration, `prefers-reduced-motion` compliant).
2. **Glassmorphic Navigation**: Scrolled glass panel header, search modal, cart counter, wishlist counter, and animated mobile menu drawer.
3. **Full-Screen Hero**: Slow camera zoom effect (`scale(1.02)` to `1.08`) with staggered editorial text animation.
4. **Sticky Camera Category Story**: Interactive 6-category camera scroll transition (*01 Mattresses, 02 Beds, 03 Sofas, 04 Recliners, 05 Pillows, 06 Bedding*).
5. **Editorial Mattress Collection**: 60/40 asymmetric showcase with quick size pickers, firmness meters, and quick view modals.
6. **Interactive Room Transformation**: Horizontal drag slider comparing ordinary bedroom setups vs Duroflex Architectural Suites.
7. **5-Step Mattress Match Quiz**: Interactive questionnaire analyzing sleeping position, firmness, temperature, and back pain for custom recommendations.
8. **Flagship Store Locator**: City search across India (Mumbai, Bengaluru, Delhi NCR, Hyderabad, Chennai) with interactive radar map preview.
9. **Full E-Commerce Suite**: Slide-over Cart Drawer, Wishlist Drawer, Search Modal, Product Detail Modal, and Toast notifications.
